# Prompt Keeper

A lightweight, dark-mode web application for saving and reusing system instruction prompts. Everything is stored locally in your browser—no backend required.

## Features
- Add, edit, and delete prompts with titles and optional summaries.
- Mark a prompt as active for quick access and copy it to your clipboard.
- Search across titles, summaries, and prompt text.
- Dark UI optimized for focused writing.

## Getting started
1. Open `index.html` in any modern browser.
2. Add your own prompts or start from the included examples.
3. Click **Use** on a card to stage it as the active prompt and quickly copy it when needed.

Data is saved to `localStorage` under the key `prompt-keeper:v1`.
